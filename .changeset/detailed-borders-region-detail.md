Add sharper borders when zoomed in and a region-detail API. With `zoom`, the map now draws detailed country borders (Natural Earth 10m) once zoomed in to 2x or more (`detailedGeometryMinScale`), and the default borders below that. The detailed data is a separate file (`dist/map-assets/countries-detailed.cjs`, about 2.4 MB, 360 kB gzipped) loaded with `import()` the first time it is needed, so the default bundle grows by only a few kB and Vite and webpack emit the data as its own chunk. It has the same countries, names and codes as the default map, with Crimea as part of Ukraine in both. `zoom={{ detailedGeometry: false }}` turns it off and `preloadDetailedCountryGeometry()` loads it ahead of time. New `detailLevel="regions"`, `detailProvider` and `onDetailStatusChange` props draw the regions of the countries in view as dashed borders once zoomed in to `regionDetailMinScale` (default 4); providers return GeoJSON in longitude / latitude, which the map projects with the current projection. New exports: `createReadyDetailResult`, `createUnavailableDetailResult`, `createFailedDetailResult`, `createIdleDetailResult`, `isReadyDetailResult`, and the `DetailProvider`, `DetailProviderResult`, `DetailLevel`, `DetailStatus`, `RegionCollection`, `RegionFeature` and `RegionCoverageStatus` types. Without `zoom`, including with `richInteraction`, the default render is unchanged and the detailed data is never loaded.
