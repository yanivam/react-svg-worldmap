# Geopolitical Policy

`react-svg-worldmap` is a thematic map package for charts and dashboards, not
for legal, diplomatic, navigational, cadastral, or authoritative boundary use.

The project does not endorse sovereignty claims. For disputed, partially
recognized, or politically sensitive territories, it records auditable metadata
instead of silently choosing a side.

## Initial Tier 1 scope

- Crimea
- Palestinian Territories
- Taiwan
- Kashmir
- Western Sahara
- Kosovo

Changes must include public evidence and should use United Nations naming,
terminology, resolutions, and processes where applicable. The bundled map
remains a single neutral global representation; metadata does not alter its
geometry or rendering.
